# eXtrategia Consulting

Sitio web corporativo de eXtrategia Consulting.

🌐 **Sitio en vivo:** [https://extrategia-consulting.vercel.app/](https://extrategia-consulting.vercel.app/)

## Tecnologías utilizadas
- HTML5 semántico
- CSS3 personalizado con variables y diseño responsivo
- JavaScript interactivo

## Estructura del proyecto
- `index.html`: Estructura principal y secciones del sitio web
- `styles.css`: Estilos, tipografía, paleta de colores y diseño adaptable
- `script.js`: Interactividad, menú responsivo y animaciones
- `assets/`: Recursos gráficos, logotipos y multimedia
